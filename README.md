# BRICKFALL

Головоломка с падающими блоками в стиле старой портативной консоли с зелёным LCD-экраном. Работает без интернета и без сборки.

## Запуск

- **Компьютер:** открыть `index.html` в браузере.
- **Телефон:** раздать папку с компьютера по локальной сети (`python -m http.server 8000`)
  и открыть на телефоне `http://<IP-компьютера>:8000`. Затем «Добавить на главный экран»:
  при открытии по http игра кешируется (service worker) и дальше работает офлайн.

## Управление

| Действие | Клавиатура | Экранные кнопки |
|---|---|---|
| Влево / вправо | ← → (A / D) | крестовина |
| Поворот против часовой | ↑ (W, Space, X) | крестовина вверх, кнопка ↻ |
| Ускоренное падение | ↓ (S), удерживать | крестовина вниз |
| Старт / пауза | Enter (P, Esc) | СТАРТ |
| Звук | M | ЗВУК |

В меню: ← → выбирают режим, ↑ ↓ выбирают стартовый уровень (0–9).

Если при повороте фигура упирается, игра сначала пробует опустить её на клетку (чтобы она заползла в дыру), потом сдвинуть вбок и только в последнюю очередь поднять.

## Режимы

- **Классика**: обычная игра.
- **Сдвиг**: после каждой поставленной фигуры весь стакан сдвигается на одну клетку вправо по кругу: столбец, ушедший за правый край, появляется слева.
- **Подъём**: по таймеру снизу появляются ряды мусора с дырками. С ростом уровня они появляются чаще.

## Очки

1 / 2 / 3 / 4 линии: 40 / 100 / 300 / 1200 × (уровень + 1), плюс 1 очко за каждую клетку ускоренного падения.
Уровень повышается каждые 10 линий, вместе с ним растёт скорость. Рекорд хранится отдельно для каждого режима в `localStorage` браузера.

## Файлы

`index.html`, `style.css`, `game.js` — сама игра.

PWA (установка и офлайн): `pwa.js` (кнопка «Установить»), `sw.js` (кеш), `manifest.webmanifest`, `icon.svg`, `icons/`.
Иконки PNG генерируются из рисунка скриптом `python tools/make_icons.py`.
После изменения файлов игры увеличьте версию `CACHE` в `sw.js`, иначе установленные копии продолжат брать старые файлы из кеша.

Кнопка «Установить» (внизу слева) видна только при открытии по http/https:
- Chrome, Edge, Android: открывает системное окно установки;
- iPhone/iPad (Safari), Safari на Mac: показывает инструкцию, потому что эти браузеры не дают сайту вызвать установку;
- в уже установленном приложении кнопка скрыта.
