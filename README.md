# BRICKFALL

Головоломка с падающими блоками в стиле старой портативной консоли с зелёным LCD-экраном. Работает без интернета и без сборки.

## Запуск

- **Компьютер:** открыть `index.html` в браузере.
- **Телефон:** раздать папку с компьютера по локальной сети (`python -m http.server 8000`)
  и открыть на телефоне `http://<IP-компьютера>:8000`. Затем «Добавить на главный экран»:
  при открытии по http игра кешируется (service worker) и дальше работает офлайн.

## Управление

| Действие | Клавиатура | Экранные кнопки |
|---|---|---|
| Влево / вправо | ← → (A / D) | крестовина |
| Поворот по часовой | ↑ (W, Space, X) | крестовина вверх, кнопка ↻ |
| Ускоренное падение | ↓ (S), удерживать | крестовина вниз |
| Старт / пауза | Enter (P, Esc) | СТАРТ |
| Звук | M | ЗВУК |

В меню: ← → выбирают режим, ↑ ↓ выбирают стартовый уровень (0–9).

## Режимы

- **Классика**: обычная игра.
- **Сдвиг**: каждые несколько фигур весь стакан сдвигается на одну клетку влево или вправо (с переносом через край). С ростом уровня сдвиги становятся чаще.
- **Подъём**: по таймеру снизу появляются ряды мусора с дырками. С ростом уровня они появляются чаще.

## Очки

1 / 2 / 3 / 4 линии: 40 / 100 / 300 / 1200 × (уровень + 1), плюс 1 очко за каждую клетку ускоренного падения.
Уровень повышается каждые 10 линий, вместе с ним растёт скорость. Рекорд хранится отдельно для каждого режима в `localStorage` браузера.

## Файлы

`index.html`, `style.css`, `game.js` — сама игра; `sw.js`, `manifest.webmanifest`, `icon.svg` — офлайн-установка на телефон.
