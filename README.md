# BRICKFALL

Головоломка с падающими блоками в стиле старой портативной консоли с зелёным LCD-экраном. Работает без интернета и без сборки.

## Запуск

- **Компьютер:** открыть `index.html` в браузере.
- **Телефон:** раздать папку с компьютера по локальной сети (`python -m http.server 8000`)
  и открыть на телефоне `http://<IP-компьютера>:8000`. Затем «Добавить на главный экран»:
  при открытии по http игра кешируется (service worker) и дальше работает офлайн.

## Управление

| Действие | Клавиатура | Экранные кнопки |
|---|---|---|
| Влево / вправо | ← → (A / D) | крестовина |
| Поворот против часовой | ↑ (W) | крестовина вверх |
| Поворот по часовой | Space, X | большая кнопка ↻ |
| Ускоренное падение | ↓ (S), удерживать | крестовина вниз, удерживать |
| Мгновенно поставить | ↓ ↓ (двойное нажатие) | крестовина вниз дважды |
| Старт / пауза | Enter (P) | СТАРТ |
| Выйти в меню | Esc: первое нажатие — пауза, второе — выход | МЕНЮ (так же) |
| Звук | M | ЗВУК |

В меню: ← → выбирают режим, ↑ ↓ выбирают стартовый уровень (0–9).

Вибрация (только Android; iPhone не даёт сайтам вибрировать), от слабой к сильной: нажатие экранной кнопки → фигура упёрлась в стенку или блоки → фигура поставлена → мгновенный сброс. Длительности задаются в `VIBE` в `game.js`.

Если при повороте фигура упирается, игра сначала пробует опустить её на клетку (чтобы она заползла в дыру), потом сдвинуть вбок и только в последнюю очередь поднять.

## Режимы

- **Классика**: обычная игра.
- **Сдвиг**: после каждой поставленной фигуры весь стакан сдвигается на одну клетку вправо по кругу: столбец, ушедший за правый край, появляется слева.
- **Подъём**: по таймеру снизу появляются ряды мусора с дырками. С ростом уровня они появляются чаще.
- **Зеркало**: каждые несколько фигур (10 на нулевом уровне, чем выше уровень, тем чаще, минимум 5) стакан отражается слева направо, а кнопки ← → меняются местами до следующего отражения. Панель показывает, сколько фигур осталось и как сейчас работают кнопки.
- **Узкий**: каждые 10 линий стакан теряет один столбец (поочерёдно слева и справа), до ширины 6. Блоки в закрывшемся столбце пропадают.
- **Гравитация**: после очистки линий все висящие клетки осыпаются вниз, как песок. Если от этого собрались новые линии, это каскад: очки за каждую следующую волну умножаются (ЦЕПЬ x2, x3…).
- **Кривые**: к обычным семи фигурам в каждом мешке добавляются 4 случайные необычные: из 1, 2 и 3 клеток или из 5 клеток (в том числе палка длиной 5).
- **Спринт 40**: убрать 40 линий как можно быстрее. Скорость не растёт; стартовый уровень задаёт её на всю партию.
- **Раскопки**: снизу лежит завал (4 + стартовый уровень рядов, в каждом по дырке). Нужно расчистить его до дна. Камни завала нарисованы сплошными.

## Очки

1 / 2 / 3 / 4 / 5 линий: 40 / 100 / 300 / 1200 / 2000 × (уровень + 1) × номер волны каскада, плюс 1 очко за каждую клетку ускоренного падения и 2 очка за клетку мгновенного сброса.
Уровень повышается каждые 10 линий, вместе с ним растёт скорость. Рекорд хранится отдельно для каждого режима в `localStorage` браузера.
В «Спринте» и «Раскопках» рекорд — лучшее время, отдельно для каждого стартового уровня; засчитывается только законченная партия.

## Файлы

`index.html`, `style.css`, `game.js` — сама игра.

PWA (установка и офлайн): `pwa.js` (кнопка «Установить»), `sw.js` (кеш), `manifest.webmanifest`, `icon.svg`, `icons/`.
Иконки PNG генерируются из рисунка скриптом `python tools/make_icons.py`.
### Офлайн и обновления

После первого открытия по http/https все файлы игры сохраняются в кеш, и дальше игра (в том числе установленная) запускается без интернета.

**После изменения файлов игры увеличьте `VERSION` в `sw.js`.** По этой версии установленные копии узнают, что вышло обновление.

Кнопка внизу слева (видна только при открытии по http/https):
- **УСТАНОВИТЬ** — игру можно установить. В Chrome, Edge и на Android открывает системное окно установки; на iPhone/iPad и в Safari на Mac показывает инструкцию (там сайт не может сам вызвать установку).
- **ОБНОВИТЬ** — приложение работает из кеша. При нажатии проверяет новую версию; если её нет, всё равно заново скачивает все файлы и перезапускается. Без сети пишет «НЕТ СЕТИ».
- **ОБНОВИТЬ!** (мигает) — найдена новая версия. Приложение само проверяет обновления при запуске и когда его снова открывают, но ставит их только по нажатию, чтобы не прерывать партию. Если не нажимать, новая версия включится после полного закрытия и повторного запуска приложения.
